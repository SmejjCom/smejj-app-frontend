Die smejj-API einbinden

smejj spricht das OpenAI-Protokoll. Wer schon ein Werkzeug hat, das mit OpenAI redet — ZCode, Cline, Cursor, das offizielle SDK —, trägt drei Angaben ein und ist fertig. Es braucht keine eigene Bibliothek.

Die drei Angaben

Basis-URL: https://smejj.com/v1

Modell: smejj-1.0

API-Schlüssel: unten erzeugen (beginnt mit smejj-live-)

Meine Schlüssel

Wird geladen …

Einmalige Anzeige. Kopieren Sie den Schlüssel jetzt — er wird nie wieder angezeigt. Gespeichert ist bei uns nur sein Prüfwert, nicht er selbst.

    Verbrauch heute

    0 Anfragen 0 Token gesamt 0 Eingabe 0 Ausgabe

    Der Zähler setzt täglich um 00:00 UTC zurück.

    Beispiel

    Mit curl:

    curl https://smejj.com/v1/chat/completions \
  -H "Authorization: Bearer smejj-live-…" \
  -H "Content-Type: application/json" \
  -d '{"model":"smejj-1.0","messages":[{"role":"user","content":"Hallo"}]}'

    Mit dem OpenAI-SDK (Python):

    from openai import OpenAI
client = OpenAI(base_url="https://smejj.com/v1", api_key="smejj-live-…")
antwort = client.chat.completions.create(
    model="smejj-1.0",
    messages=[{"role": "user", "content": "Hallo"}],
)
print(antwort.choices[0].message.content)

    Modelle

    smejj-1.0 — Allzweck, die Voreinstellung.

    smejj-1.0-fast — kurze Antwortzeit für knappe Fragen.

    smejj-1.0-code — Programmieren, tiefe Spur.

    smejj-1.0-reasoning — mehrschrittiges Denken.

    Welches Modell dahinter rechnet, entscheidet smejj und kann sich ändern — Ihr Aufruf bleibt gleich.

    Grenzen

    60 Anfragen Vorrat je Konto, eine pro Sekunde kommt zurück (HTTP 429 mit Retry-After, wenn er leer ist).

    Tageskontingent je Konto in Token; bei Erreichen antwortet die API mit 429 daily_quota_exceeded.

    Unterstützt: stream, temperature, max_tokens, tools, tool_choice, response_format.
